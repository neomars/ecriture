# Écriture Privacy Policy / Politique de Confidentialité

*Last updated / Dernière mise à jour : September 17, 2026*

---

# English Version

This privacy policy applies to the software **Écriture**, an open-source desktop application dedicated to writing assistance and literary creation.

## 1. Data Collection and Processing
The software is designed with a strictly offline-first architecture. The application does not collect, record, share, or transmit any personal data, hardware or software identifiers, or usage statistics.

## 2. Storage of Manuscripts and Projects
All of your data, including your manuscripts, drafts, notes, research, and configuration settings, is stored **exclusively locally** on your computer's hard drive. The application does not communicate with any remote servers and does not perform any backups to third-party cloud services.

## 3. Artificial Intelligence and Local Execution
Assistance features based on artificial intelligence models run entirely autonomously on your own hardware. Text processing, contextual analysis, and content generation require **no external network requests**. Your manuscripts never leave your machine and are not sent to any cloud APIs.

## 4. Telemetry and Tracking
The application is completely free of tracking mechanisms, behavioral analysis tools (analytics), automated crash reporting, or telemetry, even in an anonymized form.

## 5. Changes to this Policy
If structural changes alter how the application interacts with data in future versions, this policy will be updated on the project repository.

## 6. Contact and Source Code
For any questions regarding the privacy of your data or to review the source code, you can visit the official GitHub repository for the project:
[https://github.com/neomars/ecriture](https://github.com/neomars/ecriture)

# Version Française

La présente politique de confidentialité s'applique au logiciel **Écriture**, une application de bureau open-source dédiée à l'assistance et à la création littéraire.

## 1. Collecte et traitement des données
Le logiciel est conçu selon une architecture strictement hors-ligne (offline-first). L'application ne collecte, n'enregistre, ne partage ni ne transmet aucune donnée personnelle, aucun identifiant matériel ou logiciel, ni aucune statistique d'utilisation.

## 2. Stockage de vos manuscrits et projets
L'intégralité de vos données, incluant vos manuscrits, brouillons, notes, recherches et paramètres de configuration, est stockée **exclusivement en local** sur le disque dur de votre ordinateur. L'application ne communique avec aucun serveur distant et n'effectue aucune sauvegarde sur des services de cloud tiers.

## 3. Intelligence Artificielle et exécution locale
Les fonctionnalités d'assistance basées sur des modèles d'intelligence artificielle s'exécutent de manière totalement autonome sur votre propre matériel. Le traitement de vos textes, l'analyse contextuelle et la génération de contenu ne requièrent **aucune requête réseau externe**. Vos manuscrits ne quittent jamais votre machine et ne sont envoyés à aucune API cloud.

## 4. Télémétrie et suivi (Tracking)
L'application est totalement dépourvue de mécanismes de pistage, d'outils d'analyse comportementale (analytics), de rapports de plantage automatisés ou de télémétrie, même de manière anonymisée.

## 5. Modifications
Si des modifications structurelles venaient à modifier la façon dont l'application interagit avec les données dans de futures versions, cette politique serait mise à jour sur le dépôt du projet.

## 6. Contact et Code Source
Pour toute question relative à la confidentialité de vos données ou pour examiner le code source, vous pouvez consulter le dépôt GitHub officiel du projet :
[https://github.com/neomars/ecriture](https://github.com/neomars/ecriture)
