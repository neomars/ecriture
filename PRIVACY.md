## 🇫🇷 Français

Écriture est un logiciel d'écriture de romans développé par Martial Limousin. Cette politique explique quelles données le logiciel traite et quand il se connecte à Internet.

### En résumé

- **Aucun compte**, aucune inscription.
- **Aucune télémétrie**, aucune statistique d'utilisation, aucune publicité, aucun traceur.
- **Vos textes restent sur votre ordinateur.** Ils ne sont jamais envoyés à l'auteur du logiciel ni à un tiers.
- **L'intelligence artificielle fonctionne entièrement en local**, sur votre ordinateur. Vos textes ne sont pas envoyés à un service d'IA en ligne.

### Données stockées sur votre ordinateur

Vos romans (chapitres, scènes, personnages, notes, objectifs), vos préférences (langue, thème) et le modèle d'IA téléchargé sont enregistrés uniquement dans les dossiers de l'application sur votre ordinateur. Vous pouvez les supprimer à tout moment en désinstallant le logiciel et en supprimant ces dossiers. Les exports (PDF, EPUB, Word…) sont enregistrés là où vous le choisissez.

### Connexions à Internet

Le logiciel se connecte à Internet uniquement dans les cas suivants. Comme pour toute connexion, le serveur contacté voit votre adresse IP ; aucune donnée personnelle ni aucun texte n'est transmis.

| Connexion | Quand | Données envoyées |
|---|---|---|
| **Téléchargement du modèle d'IA** depuis Hugging Face (huggingface.co) | Une seule fois, quand vous activez l'assistant IA | Aucune (simple téléchargement de fichier) |
| **Vérification des mises à jour** sur GitHub (api.github.com) | Au démarrage | Aucune (lecture du numéro de la dernière version publiée) |
| **Polices et styles de l'interface** (Google Fonts, cdn.tailwindcss.com) | À l'affichage de l'interface | Aucune (simple téléchargement de fichiers) |
| **Bouton de don Ko-fi** (ko-fi.com) | À l'affichage de l'interface ; la page Ko-fi ne s'ouvre que si vous cliquez | Aucune de la part du logiciel |

Ces services tiers ont leurs propres politiques de confidentialité : [Hugging Face](https://huggingface.co/privacy), [GitHub](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement), [Google](https://policies.google.com/privacy), [Ko-fi](https://more.ko-fi.com/privacy).

### Signalement d'un contenu généré par l'IA

Vous pouvez signaler un contenu généré par l'IA. Rien n'est envoyé automatiquement : le logiciel prépare un message que vous pouvez relire et modifier, puis ouvre soit une page GitHub (publique, envoyée avec votre compte GitHub), soit votre logiciel de messagerie vers ecriture.app@gmail.com. Le message n'est envoyé que si vous le validez vous-même. Il contient le texte généré, le motif choisi, la fonction d'IA utilisée, la version du logiciel, la langue et le nom du modèle, et éventuellement votre commentaire. Ces signalements servent uniquement à améliorer le logiciel.

### Enfants

Le logiciel ne collecte aucune donnée personnelle, y compris celles des enfants.

### Modifications

Toute modification de cette politique sera publiée sur cette page.

### Contact

Pour toute question : **ecriture.app@gmail.com**, ou via les [issues GitHub](https://github.com/neomars/ecriture/issues).

## 🇬🇧 English

Écriture is novel-writing software developed by Martial Limousin. This policy explains what data the software handles and when it connects to the Internet.

### In short

- **No account**, no sign-up.
- **No telemetry**, no usage statistics, no ads, no trackers.
- **Your writing stays on your computer.** It is never sent to the author of the software or to any third party.
- **The artificial intelligence runs entirely locally**, on your computer. Your texts are not sent to any online AI service.

### Data stored on your computer

Your novels (chapters, scenes, characters, notes, goals), your preferences (language, theme) and the downloaded AI model are stored only in the application's folders on your computer. You can delete them at any time by uninstalling the software and removing those folders. Exports (PDF, EPUB, Word…) are saved wherever you choose.

### Internet connections

The software connects to the Internet only in the following cases. As with any connection, the server contacted sees your IP address; no personal data and no text is transmitted.

| Connection | When | Data sent |
|---|---|---|
| **AI model download** from Hugging Face (huggingface.co) | Once, when you enable the AI assistant | None (plain file download) |
| **Update check** on GitHub (api.github.com) | At startup | None (reads the latest published version number) |
| **Interface fonts and styles** (Google Fonts, cdn.tailwindcss.com) | When the interface is displayed | None (plain file download) |
| **Ko-fi donation button** (ko-fi.com) | When the interface is displayed; the Ko-fi page only opens if you click | None from the software |

These third-party services have their own privacy policies: [Hugging Face](https://huggingface.co/privacy), [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), [Google](https://policies.google.com/privacy), [Ko-fi](https://more.ko-fi.com/privacy).

### Reporting AI-generated content

You can report AI-generated content. Nothing is sent automatically: the software prepares a message that you can review and edit, then opens either a GitHub page (public, sent with your GitHub account) or your e-mail client addressed to ecriture.app@gmail.com. The message is only sent if you confirm it yourself. It contains the generated text, the chosen reason, the AI feature used, the software version, the language and the model name, and optionally your comment. These reports are used only to improve the software.

### Children

The software does not collect any personal data, including children's.

### Changes

Any change to this policy will be published on this page.

### Contact

For any question: **ecriture.app@gmail.com**, or through the [GitHub issues](https://github.com/neomars/ecriture/issues).
